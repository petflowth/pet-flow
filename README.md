# PetFlow Web v2

เว็บใหม่แยก — หน้าลูกค้า (LINE LIFF) + หลังบ้านเจ้าของ

## รัน dev

```bash
cd web
npm install
npm run dev
```

- **ลูกค้า:** http://localhost:3000/app
- **หลังบ้าน:** http://localhost:3000/admin/login (รหัสเริ่มต้น `petflow2026`)

## Deploy (Vercel) — เจ้าของทำครั้งเดียว

1. Push repo ไป GitHub
2. เข้า [vercel.com](https://vercel.com) → Import project → เลือกโฟลเดอร์ `webapp`
3. ใส่ Environment Variables:

| ตัวแปร | ค่า |
|--------|-----|
| `NEXT_PUBLIC_LIFF_ID` | LIFF ID จาก LINE Developers |
| `NEXT_PUBLIC_ADMIN_CODE` | รหัสหลังบ้านที่ต้องการ |

4. Deploy → ได้ URL เช่น `https://petflow.vercel.app`
5. ตั้ง LIFF Endpoint = `https://your-url.app/app`
6. ใส่ลิงก์ใน Rich Menu LINE OA @petflow

## ตั้งค่าที่ต้องทำต่อร้าน (นอกจาก LINE)

**ห้องพัก — ตั้งค่า > ห้องพัก**

ตารางห้องว่างและผังห้องคำนวณจากสองค่านี้ ตั้งผิดแล้วจะรับลูกค้าได้น้อยกว่าจริง หรือรับเกินห้องที่มี

| ช่อง | ความหมาย |
|---|---|
| จำนวนห้องจริง | ห้องที่มีอยู่จริง — **ห้องเชื่อมใส่ 0** |
| จุแมวได้กี่ตัว/ห้อง | แมวของบ้านเดียวกันช่วงวันเดียวกันนอนรวมห้องได้ถึงจำนวนนี้ (คนละบ้านไม่รวมกันเสมอ) |
| 🔗 ห้องเชื่อม | ห้องนี้เกิดจากเปิดห้องจริงถึงกันกี่ห้อง เช่น Duo = ห้อง S 2 ห้อง |

ห้องเชื่อมไม่ใช่ห้องเพิ่ม — จอง 1 ชุดจะกินห้องจริงตามที่ตั้งไว้ ระบบเลือกห้องที่เลขติดกันให้ก่อน

**รับเฉพาะจองล่วงหน้า — ตั้งค่า > ข้อมูลร้าน**

เปิดถ้าร้านไม่รับ walk-in จะขึ้นป้ายบอกลูกค้าในหน้าบริการ/ห้องพัก/อาบน้ำ (ปิดไว้เป็นค่าเริ่มต้น แก้ข้อความได้)

**แต้มลูกค้า Member — ตั้งค่า > ข้อมูลร้าน**

ให้แต้มรอบเดียวพอ ค่าเริ่มต้นคือให้ตอนเติมเครดิต (คิดจากเงินที่จ่ายจริง ไม่รวมโบนัส) และไม่ให้ซ้ำตอนตัดใช้

> **หมายเหตุบัญชี:** ตัดเครดิต Member ไม่นับเป็นรายรับ เพราะรับเงินไปแล้วตอนลูกค้าซื้อเครดิต
> ถ้านับอีกรอบยอดขายจะบวมเป็นสองเท่าของเงินที่เข้าจริง

## สถานะนัด

จอง → ยืนยัน → **พร้อมรับกลับ** → เสร็จ

"พร้อมรับกลับ" กดแล้วลูกค้าได้การ์ดแจ้งทาง LINE ทันที (ดูตัวอย่างก่อนส่งได้) ลดคำถาม "น้องเสร็จยัง"

"ไม่มา" แยกจาก "ยกเลิก" เพื่อดูได้ว่าลูกค้าคนไหนไม่มาโดยไม่แจ้ง — ไม่มาแล้วจะไม่ส่งแจ้งเตือนต่อ ไม่ขึ้นตาราง Telegram และคืนห้องให้
